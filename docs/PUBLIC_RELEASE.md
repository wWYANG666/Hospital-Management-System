# 公开分享版说明

## 发布范围

本目录包含整理后的 Java 后端、Vue 前端、测试源码、构建文件、数据库建表与迁移脚本、启动脚本及文档。手工数据库文件已统一放到 `database/`，首次初始化使用 `database/init.sql`。主项目的个人整理记录不随分享版发布。

从原项目导出时已排除：

- 本地开发仓库 `.git`、本地历史、远程地址与个人作者元数据
- 本地环境文件、IDE 设置和运行配置
- 按用户编号保存的头像及用户上传内容
- 数据库备份、业务测试记录、请求快照、日志和截图
- 论文、答辩稿、简历笔记和临时文档
- Maven 编译产物、前端依赖和生成的 SPA 文件
- 未核实来源的旧插画；页面统一使用已检查的生成医院插画

生成插画的公开 C2PA 来源证明保留，用于说明其 AI 来源；不包含用户姓名、邮箱、工作区路径或私有 API Key。

## 配置

数据库、初始管理员和 AI Key 均通过环境变量或外置本地配置注入。模板为 `config/application-local.example.properties`。

外置 `config/application-local.properties` 被 Git 忽略，且不位于 Maven 资源目录，不会被打入 JAR。分享版未设置初始管理员密码，也不提供可直接登录的用户数据。

外部 AI 默认关闭，支付为模拟流程。数据库脚本不导入患者或临床记录。可选的科室、药品与检查种子数据属于演示资源数据。

## 公开 Git 历史

本次以整理、验证后的完整源码建立唯一的初始提交，并整体替换公开仓库的 main 分支。作者与提交者使用公开 GitHub 用户名及 noreply 邮箱，不继承之前的公开或本地开发提交历史。README 保留已有的内容调整。

整份替换只能更新本次推送的 Git 分支；GitHub 上已缓存的旧提交页面、旧克隆和其他已有副本可能保留之前的元数据。
